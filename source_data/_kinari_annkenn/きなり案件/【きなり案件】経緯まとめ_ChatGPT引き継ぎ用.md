## 経緯（時系列）

### Phase 1：初回接触（3月初旬）

- きなりさんからLINEでヒアリングが来た
- 「事業の時間配分」「今後の方向性」「理想のゴール」の3問形式
- ChatGPTと相談して、以下の方針で返信した：
  - アダルト要素・裏垢の存在は伏せる
  - 「出張型リラクゼーションサロン＋情報コンテンツ販売」で説明
  - 「選ばれる側」ではなく「見極める側」のスタンスを維持

### Phase 2：Zoom準備（3/2〜3/3）

- きなりさんから日程提示 → 3/3 19:00を選択
- カメラオフ（音声のみ）で参加することを決定
- ChatGPTから以下の助言を受けた：
  - きなりさんのメッセージは抽象ワードが多い（「壁は突破できます」「ヒントを渡せます」等）
  - 具体的な業種・事例・プロセス・費用が一切出ていない
  - 「テンプレ型セールス導線」の可能性が高い

### Phase 3：Zoom本番（3/3、約2時間）

- きなりさんのピッチ内容：
  - コンテンツ制作と顧客対応に時間を取られている → AIで仕組み化しましょう
  - 「専門性 × AI」の旗を立てる → あなたの専門性で人を集める
  - 集まった見込み客をきなりさんのAI部門に流す → 成約したら報酬
  - 3ヶ月の「並走」期間で仕組みを作る
- 提示された条件：
  - 費用：33万円（税別）、3ヶ月契約
  - 報酬：成約1件あたり最低5万円〜、基本20%の固定コミッション
  - 例：30万の案件 → 6〜8万円、350万の案件 → 120万円（実例と主張）
  - 返金特約あり（ただし条件が曖昧）
  - 36人中7人が1ヶ月で初期投資回収（本人談）

- Zoom直後の私の感想：「直感では33万円払うのありだなと思った」

### Phase 4：ChatGPTからの警告（3/3〜3/4）

ChatGPTが8つのレッドフラッグを指摘：

1. 具体的な商品がまだ存在しない（「商品設計からやる」）
2. 実装内容が「人によって違う」でROI計算不能
3. 具体的なクライアント名・事例の提示なし
4. **きなりさん本人が「3ヶ月後も僕が必要になるよう設計してます」と発言** ← 依存設計
5. 「今決めないと枠が埋まる」 ← スカーシティ戦術
6. 122人の市場独占スキーム
7. 返金条件が未定義
8. アフィリエイトモデルなのにそう名乗っていない

### Phase 5：契約交渉（3/3〜3/4）

- 私から「前向きに検討したいので契約書と成果物一覧を書面でください」と依頼
- きなりさんの返答：「合意があった時点で法律としては成立するけど、心配だと思うから書面渡す。返送いらないよ」
  - ChatGPTの指摘：「返送不要の契約書 ＝ あなただけを縛る書面になり得る」
- 「検討したい」と言った時にきなりさんが少し怒った → ChatGPTは「bad sign」と判断

### Phase 6：支払い決定（3/4）

- **最終的に33万円を支払い、3ヶ月契約を開始した**
- 支払い方法：PayPal
  - ChatGPTの指摘：「PayPalは無形サービスの購入者保護が弱い」
- 決め手：
  - きなりさんのスキルと経験への期待
  - AI学習・プロデュース手法を学べること
  - 「自分が全部やらなくていい仕組み」への魅力
  - もともとBtoBだからちゃんとしてるという判断

### Phase 7：契約後の状況（3/4以降〜現在）

- きなり案件として「X→note→LINE→Zoom」の導線構築に取り組んでいる
- 私の担当範囲：LINE登録までのリストイン（X投稿・note・LINE誘導）
- Zoom以降の営業・成約は別担当（きなりさん側）
- 成約報酬：1件5万円〜
- 現在の成果：まだ成約なし
- LINE流入：約1.4人/日
- 課題：Zoom移行時に離脱がある（営業への抵抗感）

## ChatGPTが出した総合評価

**良い点：**
- 学びの機会としては本物（AI活用・プロデュース手法）
- 実装サポートは実在する
- 詐欺ではない（BtoB経験があり事業は実在）
- コミッション型なので成果が出れば収益は得られる

**リスク：**
- 依存設計が意図的（3ヶ月後も必要になるように作られている）
- 私の役割は「旗持ち＝広告塔」であり、事業オーナーではない
- IP（顧客データ・手法・アカウント）の帰属が不明確
- コミッション率が案件によって変動し、事前に確定しない
- 返金条件が曖昧

## 契約時に確認すべきだったが未確認のポイント

1. 成果物リスト（具体的に何が納品されるか）
2. 返金条件の明文化（どういう場合に返金されるか）
3. コミッション定義（いつ・何を基準に・いくら計算されるか）
4. アカウント帰属（構築したSNSやLINEは誰のものか）
5. 3ヶ月後の引き継ぎ条件（独立運用できる状態になるか）
6. 顧客データの所有権
