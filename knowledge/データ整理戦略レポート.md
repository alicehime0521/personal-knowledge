## 5. 推奨アクション

### Phase 1: 即時対応（重複削除・軽量化）
1. **重複ファイルの統一** → 推定2.5GB以上削減
   - `source_data` とメインフォルダの重複を整理（source_dataを正とするか、メインフォルダを正とするか決める）
2. **100MB超ファイルを `.gitignore` に追加** → Git LFS不要でGitHub管理可能に
3. **空・不要フォルダの削除** → 名称未設定フォルダ等

### Phase 2: 構造整理（フォルダ再編）
推奨ディレクトリ構成：
```
knowledgesakusei/
├── knowledge/          ← 完成ナレッジ（GitHub管理の核）
├── source_data/        ← 1次ソースデータ（参照用）
├── business/           ← ビジネス教材・コンサル・運用代行
├── music/              ← M.C.U・バンド・音楽活動
├── finance/            ← 税務・経理・領収書
├── private/            ← プライベート（.gitignore推奨）
├── media_local_only/   ← 動画・大容量ファイル（.gitignore）
└── archive/            ← 不要だが念のため保持するもの
```

### Phase 3: ナレッジ化（今後の作業）
1. ChatGPT JSON（86ファイル）から未抽出のナレッジを段階的に抽出
2. 各案件の1次ソースからプロジェクトナレッジを作成
3. パーソナルナレッジ_作成中.md と knowledge/ の関係を整理
