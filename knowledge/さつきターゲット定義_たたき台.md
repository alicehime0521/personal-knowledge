## 2. ターゲットの悩み（5つの根深いニーズ）

実データ＋朋香自身の原体験から抽出。おさるの講義でいう「ドリルではなく穴が欲しい」の構造で整理。

### 表面の悩み → 本質的な欲求

**① 「AIを使いたいけど、何から始めればいいかわからない」**
→ 本質: 取り残される恐怖。周りがAIで効率化しているのに、自分だけ手作業で戦っている焦り

**② 「一人で全部やっていて、体力的にも時間的にも限界」**
→ 本質: 労働集約型から抜けたい。でも「仕組み化」の方法を誰にも教えてもらったことがない

**③ 「SNSで発信しているけど、集客に繋がらない」**
→ 本質: 自分の価値を言語化できない。何をどう発信すれば人が来るのかの設計図がない

**④ 「高額なAIコンサルや講座は怖い。本当に自分に合うのか不安」**
→ 本質: 過去に高額教材で失敗した経験がある（or 周りで失敗した人を知っている）。信頼できる人から小さく始めたい

**⑤ 「自分のビジネスは特殊だから、AIなんて関係ないと思っていた」**
→ 本質: リハビリ、セラピスト、教室運営、施術系など「対人サービス」の人ほど「AIは自分には無縁」と思い込んでいる

## 3. ターゲットの理想の未来（求めている最高の状態）

1. **「自分が動かなくても回る仕組み」が1つでもある状態** — 予約管理、顧客対応、集客導線のどれか1つでもAIで自動化されている安心感
2. **「AIを使いこなしている自分」という自信** — 周りに「すごいね」と言われる。時代に乗れている実感
3. **労働時間を減らしても収入が落ちない構造** — 体を壊す前に仕組みを作れた。時間の余白ができた
4. **「この人に頼めば大丈夫」という伴走者がいる安心感** — 一人で悩まなくていい。相談できる人がいる
5. **小さく始めて、実際に成果が出た体験** — 5万円の投資で目に見える変化があった。次のステップに進む勇気が出た

---

## 4. ターゲットの避けたい未来（恐怖・不安）

1. **AIに置き換えられて、自分の仕事がなくなる** — 使う側にならなければ淘汰される
2. **このまま一人で全部やり続けて、体を壊す** — 朋香自身が経験した「労働集約→消耗→破綻」のサイクル
3. **高額講座に騙されて、また無駄金を使う** — 100万円払って何も変わらなかった人を知っている
4. **周りがどんどんAIで進んでいるのに、自分だけ取り残される** — SNSで「AI活用術」の投稿を見るたびに焦る
5. **「もう遅い」と感じて、行動すらできなくなる** — AI市場の変化が速すぎて、もう追いつけないと諦める

## 5. ターゲットペルソナ（代表的な3タイプ）

### タイプA:「対人サービス型の個人事業主」
- **職業例:** セラピスト、整体師、理学療法士、ネイリスト、パーソナルトレーナー、ヨガ講師
- **状況:** 技術はあるが、集客・予約・顧客管理を全部一人でやっている。SNS発信もしているが成果に繋がらない
- **AIへの態度:** 「自分の仕事は対面だからAIは関係ない」と思っているが、実は事務作業やSNS運用でAIが使えることに気づいていない
- **響くメッセージ:** 「施術以外の時間を半分にできたら、もっとお客様に集中できませんか？」
- **成約例:** ワニベさん（理学療法士）

### タイプB:「発信はしているけど仕組みがない個人」
- **職業例:** SNS発信者、フリーランス、副業中の会社員、シングルマザーで在宅ワーク
- **状況:** Threads、Instagram、noteなどで発信しているが、フォロワーが伸びない・マネタイズできない。やり方は自己流
- **AIへの態度:** AIツールは触ったことがある。ChatGPTで文章を書いたりはしている。でも「仕組み」としてビジネスに組み込む方法がわからない
- **響くメッセージ:** 「毎日投稿しても集客ゼロだった私が、AIで導線を作ったら月21人がLINEに来た話」
- **成約例:** ゆめさん（シングルマザー・Threads発信者）

### タイプC:「事業は回っているが、スケールの壁にぶつかっている」
- **職業例:** 個人事業主（店舗経営、教室運営、コンサルタント）
- **状況:** 既存客はいるが新規が増えない。業務が属人化していて自分が倒れたら終わり。スタッフに任せたいが仕組みがない
- **AIへの態度:** AIの可能性は感じているが、「自分の業種で具体的に何ができるのか」が見えない。高額コンサルは避けたい
- **響くメッセージ:** 「あなたの業務の"ここ"をAIに任せるだけで、月20時間が空きます」
- **成約例:** 業務改善案件（個人事業主・60〜80万円規模）

## 6. ターゲット定義で未確定の論点（朋香に確認したいこと）

1. **性別比率:** ゆめさんは女性、ワニベさんは男性。さつきの世界観は「女性向け」に寄せるのか、性別不問にするのか？
   - 現在のnote・固定ポストの世界観は女性的なトーン
   - ただし業務改善案件は性別問わず来る可能性が高い

2. **年齢層:** 成約者の年齢データがない。さつきのターゲットは20代後半〜40代前半くらいのイメージか？

3. **「過去の自分」軸 vs 「実データ」軸:** Xポスト設計案では「過去のさつき自身（夜職/体を削る働き方から抜けたい女性）」がターゲットとされていた。実際の成約者はそこに限定されていない。どちらに寄せるか？
   - 選択肢A: 「過去の自分」に絞る → 共感は深いが、市場が狭い
   - 選択肢B: 「個人事業主×AI仕組み化」で広く取る → 成約実データに沿っている
   - 選択肢C: 世界観は「過去の自分」寄りだが、実際のサービスは広く受ける（ブランディングとサービス範囲を分離）

4. **きなり案件の外の視点:** フェーズ2以降で自分のプロダクトを作る時、このターゲット定義はそのまま使えるか？ それとも今はきなりフェーズ1（LINE流入まで）に特化して、後で拡張するか？
